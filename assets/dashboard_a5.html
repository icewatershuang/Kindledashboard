▾ 内容与显示
提醒 / 诗歌（置顶）
下面每条事项各设一个时段，到点才出现在首页；最多 5 条。
范围 30~86400，默认 300（5 分钟）。中英文严格轮换，逐条往下走。
同一时刻显示几首诗（每条各自带一行小字的「作者 · 诗名」）。 条数越多、每首占的高度越小，换诗时整批一起换。
只有当前时间落在某条事项的开始～结束之间，它才会出现在首页天气预报下方； 过了结束时间自动消失，空出来的位置由天气预报多排几天补上（预报最少保留 3 天）。
显示模式（置顶）
切换立即生效并记住选择；墨水屏上黑底白字在夜间更省眼。
板块字号
选一个百分比，所有板块一起变；下面那些单独的下拉仍然可以再微调。
百分比是相对出厂字号。改动立即生效并自动保存，不用点【保存设置】。 放大后放不下的板块会自动回退，不会溢出屏幕。
界面字号（电台 / AI / 设置）
这三类界面（双击 Radio 的电台界面、AI 问答界面、本设置页）默认字号完全一致， 并且跟着【系统基准字号】一起缩放。想让它们重新一致，选一次【三界面统一】； 想单独调某一个，用下面三行。
通用
日历为固定显示内容，不提供隐藏选项。
开启后主页各板块的位置、间隔与字号严格保持默认（或后台设置）的值，新闻刷新等内容变化不会自动挪动；关闭则恢复旧版按内容自适应。
主页与设置页所有文字的整体基准。把它调到和你手机「设置 → 显示 → 字体大小」一致，整页就与系统字号对齐；下面【板块字号】里各板块的下拉仍可在此之上单独微调。
仅在【锁定主页版面】开启时生效：把整页缩放钉死为选定比例，设备转屏 / 软键盘等视口抖动都不再改变大小。改完即时保存。
锁定模式下板块之间的固定间距，不再随内容多少自动撑开 / 收缩，日历 / 天气 / 诗歌因此保持相邻、不分离。
▸ 天气与预警
天气
范围 300~86400（5分钟~24小时），默认 1800（30分钟）。改完点最底下【保存设置】。
可在 3~14 天之间选。空间不够时会自动少排几天（最少 3 天）， 好把预警 / 提醒 / 诗歌的位置留住；空间富余也不会超过这里选的天数。
可直接填写中文城市名（如 苏州、乌鲁木齐）或经纬度 "39.9,116.4"。点上方按钮立即切换，也可关掉【自动定位城市】后用【保存设置】统一生效。
天气 / 灾害 / 地震 预警（仅中国权威机构）
极端天气按本地预报正文里是否出现暴雨、大暴雨、特大暴雨、雷暴、雷电、台风、飓风、龙卷风等关键词判定， 排在官方预警之后，最多 2 条。它和上面「只看中国权威机构」是两件事：官方那项只管权威机构的正式发布。
v16 起默认落在「广东全省」：灾害接口是按省拉数据的，只锁汕头会命中极少、预警块常年空白；广东档里汕头条目仍然排最前，优先级没丢。想只看汕头可在此改回。只采用中国权威机构的正式发布：气象灾害预警来自「中央气象台（中国气象局）」，地震速报来自「中国地震台网 CENC（中国地震局）」；境外条目一律剔除。地区选「广东 汕头」只显示汕头；选「广东全省」覆盖广东并把汕头排在最前；选「中国大陆全境」则显示大陆各地。预警地址里的 {prov} 会自动替换成省份名。数据缓存本地，断网时显示上次结果。老设备若 HTTPS 握手失败，地震源会自动退到同地址 http 再试一次。
搜索 / 添加天气城市
支持中文城市名（苏州 / 乌鲁木齐），也支持只打半个字（如「州」）做模糊查。
▸ 新闻资讯
新闻 RSS 源
每条源单独一行：改名称/当前链接后点本行【保存】；点【删除源】移除整条；每条【备链】可单独【删除】（删失效的备链），【清空当前】可删掉失效的正在使用的链接。底部【+ 新增一行】可添加。全部改完点页面底部【保存设置】生效。
搜索 / 添加新闻源
点「测试并添加」会真的去拉一次这个源，能拉到 10 条以上才算通过， 避免加进去一个死链。常用源列表可直接点选。
新闻关键词搜索
通用搜索RSS接口不稳定（Bing会跳转、Google News常不可达），故需你自备可用接口。 填了模板+关键词后，搜索结果会并入新闻池。留空则不启用。

▸ 本机与常驻
网络诊断
新闻拉不到的时候点一下，它会把每个源真拉一次， 列出耗时和失败原因。把结果截图发我，我就能定位是哪一环断了。
本机常驻（仅 APK 生效）
开机自启动已内置
清单里已注册 BootReceiver：开机、解锁、跨日、换时区、应用升级都会自动把仪表盘拉起来。首次安装后请手动打开一次本应用；部分 ROM 还要在「自启动管理 / 后台管理」里放行本应用。
后台常驻前台服务 + 看门狗
KeepService 常驻前台，另有看门狗定时巡检，进程被系统回收后会在几分钟内拉回。配合下面的【加入省电白名单】效果最好。
屏幕常显常亮 + 可作桌面
本版已给主界面加上 HOME 类别：想让它像桌面一样一直在屏幕上，到系统「设置 → 应用 → 默认桌面 / 主屏幕」里选本应用即可，之后按主页键就回仪表盘。
